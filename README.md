-> Task Manager
- A simple Task Management web application built with Python, Streamlit, and SQLite. It allows users to create, view, complete, filter, and delete tasks through a simple interface. Link : https://task-manager-hyghgzk475chhgykbrsl42.streamlit.app/

-> Features
- Add new tasks
- Add task descriptions
- View all tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- SQLite database for storing tasks

-> Technologies Used
- Python
- Streamlit
- SQLite
